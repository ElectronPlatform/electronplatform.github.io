Electron is actively developed and Early Public Preview 1 is available without charge while the platform continues to mature. Testing, practical feedback and shared hardware knowledge are the most direct ways to help.

Supporting Electron

Practical support for active development

Community participation helps Electron improve compatibility, documentation and release quality. It can also make more hardware testing and development work possible.

Preview participation is independent from financial support. Everyone receives the same opportunity to test, report problems and contribute useful information.

Community first

More than financial support

Useful testing and clear evidence are as valuable to Electron as financial contributions. Different forms of support solve different project needs.

Report a website issue → Review the documentation → Share compatibility feedback →

How support helps

Real project needs

Support can be applied to specific development and release needs rather than vague promises.

Hardware coverage

Additional Proxmark3 hardware, RFID cards and tags, USB adapters and accessories for compatibility testing.

Development equipment

Equipment needed to reproduce hardware behaviour and compare results across supported setups.

Documentation

Clear installation guidance, tested examples, screenshots and updates when behaviour changes.

Website and distribution

Website hosting, release storage and other future distribution costs.

Apple release preparation

Apple Developer requirements, code signing and notarization for a smoother MacOs installation experience.

Compatibility testing

Time and equipment for testing PM3 clients, firmware capabilities and clean installation environments.

Looking ahead

An evolving platform

Electron may expand over time with additional editions, services or commercial offerings as development continues. No particular model is promised.

Any future licence, edition or commercial model will be explained clearly before it affects users. Public Preview participation does not create an entitlement or obligation tied to financial support.

Voluntary financial support

PayPal

PayPal is the first external support option prepared for Electron. The website does not process payments, track contributions or connect support to application access.

PayPal support is not currently enabled

Financial support is voluntary appreciation. It does not affect Preview access and does not purchase guaranteed features, timelines or individual support.

Thank you

Thank you for helping Electron improve

Every careful test, useful bug report, documentation correction, hardware observation and voluntary contribution helps the project grow. Each form of support is valued equally for the practical difference it can make.
