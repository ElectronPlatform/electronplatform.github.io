Features

Electron modules

Electron is built around one durable local RFID Collection. Scanning, intelligence, knowledge, reports and hardware tools create, explain or enrich its records.

Platform modules

Standard Firmware

Start without changing your Proxmark3

Standard Proxmark3 v4.21611 firmware supports core Electron workflows, including HF/LF scanning, Device Console, Card Viewer and basic diagnostics. Capabilities that are not reported stay visibly unavailable.

Device Studio Firmware

Additional verified hardware capabilities

The optional Electron Device Studio firmware can add structured hardware status, LED status, Safe Mode, board mapping and snapshots. Electron discovers these capabilities instead of assuming them from a device name.
