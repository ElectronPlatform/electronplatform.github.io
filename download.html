Download & Installation

This is the official download and installation guide for Electron. Apple Silicon and Apple Intel are the official Mac Preview targets and share the same features, documentation, licensing and security model. Choose the installer that matches your Mac. Both provide 30 days of full application access from first launch.

Distribution notice

Early Public Preview

This Early Public Preview is distributed without Apple Developer ID signing or Apple notarization.

This allows the project to gather real-world feedback before investing in Apple's Developer Program. MacOs may therefore ask the user to confirm the application during first launch.

The published DMG has been checked against its public source revision. The matching source archives and checksums are available with the official GitHub release.

System requirements

Before you install

  • Use the architecture-matched installer for Apple Silicon (arm64) or Apple Intel (x64).
  • Both architecture-specific installers are published and verified; choose the one that matches your Mac.
  • A compatible Proxmark3 and a working USB-C or USB-A connection.
  • Permission to test every RFID card, tag or device you use.
  • Internet access for downloads and current documentation; core Collection data remains local.

Exact MacOs versions and packaged PM3 requirements will be stated with the approved installer.

Installing on MacOs

Normal installation

  1. Download the official Electron DMG from this page.
  2. Open the downloaded DMG.
  3. Drag Electron into the Applications folder.
  4. Eject the Electron installer.
  5. Open Electron from Applications.

MacOs security

If MacOs asks you to confirm the application

Electron is a new application and this Early Public Preview is not Apple Developer ID signed or notarized. MacOs may therefore show messages such as “Electron cannot be opened because it is from an unidentified developer” or “Apple could not verify this application.” This expected message describes the distribution status; it does not by itself show that the application is unsafe.

Method 1

Open from Applications

  1. Open the Applications folder.
  2. Right-click or Control-click Electron.
  3. Select Open.
  4. Select Open again when MacOs asks for confirmation.

Method 2

Use Privacy & Security

  1. Try to open Electron once, then open System Settings.
  2. Select Privacy & Security.
  3. Scroll to the Security section.
  4. Select Open Anyway for Electron and confirm.
  5. Open Electron again if MacOs asks you to do so.

Use only Apple's normal Open or Open Anyway workflow, and only for an installer obtained through the official Electron website after its SHA-256 matches. Do not disable MacOs security or use Terminal commands to remove its protection.

First launch

What to expect

  • Electron creates local settings and support folders for the Preview.
  • A local Installation ID is generated for Preview access information.
  • The standard Preview period starts on this first launch and lasts 30 days.
  • During the final five days, Electron shows a reminder. After expiry, the full app requires a valid signed Preview Extension Key.
  • Preview expiry does not delete your saved RFID Collection.
  • No Internet account is required to use the local application.
  • Your RFID Collection remains on your computer.
  • Nothing is submitted as feedback unless you deliberately choose what to share and send it.

Connect your Proxmark3

Start with the connection status

  1. Connect the Proxmark3 directly by USB.
  2. Open Device Console and select Check Device.
  3. If USB is detected but no session is active, select Connect Device.

USB detectedThe computer can see a compatible USB device.

Connected sessionElectron has an active PM3 session and can communicate with the device.

Future updates

Replacing a Preview build

Unless the release notes say otherwise, a newer Preview application can replace the earlier Electron application in Applications.

  • Quit Electron before replacing it.
  • Read the release notes for that build first.
  • Back up important Collection data before updating.
  • Follow any build-specific instructions instead of assuming a migration.
