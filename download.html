System requirements

Before you install

  • Current validation target: a Mac with Apple Silicon.
  • A compatible Proxmark3 and a working USB-C or USB-A connection.
  • Permission to test every RFID card, tag or device you use.
  • Internet access for downloads and current documentation; core Collection data remains local.

Exact macOS versions and packaged PM3 requirements will be stated with the approved installer.

Installing on macOS

Normal installation

  1. Download the official Electron DMG from this page when it becomes available.
  2. Open the downloaded DMG.
  3. Drag Electron into the Applications folder.
  4. Eject the Electron installer.
  5. Open Electron from Applications.

macOS security

If macOS asks you to confirm the application

Electron is a new application. Early Public Preview builds may show messages such as “Electron cannot be opened because it is from an unidentified developer” or “Apple could not verify this application.” This can happen while full Apple code signing and notarization are still being prepared; it does not by itself mean the application is unsafe.

Method 1

Open from Applications

  1. Open the Applications folder.
  2. Right-click or Control-click Electron.
  3. Select Open.
  4. Select Open again when macOS asks for confirmation.

Method 2

Use Privacy & Security

  1. Try to open Electron once, then open System Settings.
  2. Select Privacy & Security.
  3. Scroll to the Security section.
  4. Select Open Anyway for Electron and confirm.
  5. Open Electron again if macOS asks you to do so.

Use these steps only for an installer obtained through the official Electron website. Confirm the release details before overriding a security message.

First launch

What to expect

  • Electron creates local settings and support folders for the Preview.
  • A local Installation ID is generated for Preview access information.
  • No Internet account is required to use the local application.
  • Your RFID Collection remains on your computer.
  • Nothing is submitted as feedback unless you deliberately choose what to share and send it.

Connect your Proxmark3

Start with the connection status

  1. Connect the Proxmark3 directly by USB.
  2. Open Device Console and select Check Device.
  3. If USB is detected but no session is active, select Connect Device.

USB detectedThe computer can see a compatible USB device.

Connected sessionElectron has an active PM3 session and can communicate with the device.

Future updates

Replacing a Preview build

Unless the release notes say otherwise, a newer Preview application can replace the earlier Electron application in Applications.

  • Quit Electron before replacing it.
  • Read the release notes for that build first.
  • Back up important Collection data before updating.
  • Follow any build-specific instructions instead of assuming a migration.
